# Meridian Heist

A top-down stealth game. You are the thief on a three-job night with the
Meridian crew: a museum gallery, a bank vault floor, and a rooftop
penthouse. Each room has patrolling guards with vision cones, sweeping
security cameras, and loot to lift. Get spotted and suspicion climbs;
fill the alarm meter and the job is blown. Grab every marked piece, then
reach the exit and vanish.

## Controls

- WASD or arrow keys — move
- Shift — sneak (slower, harder to spot)
- 1 — toss a coin lure; the nearest guard walks over to check it
- 2 — hack the cameras, shutting them down for a few seconds
- 3 — drop a smoke cloud to hide in
- P — pause, M — mute, R — retry after getting caught

## Levels

1. Museum Gallery — learn the cones, lift three star pieces.
2. Bank Vault — tighter corridors, more cameras, four vault pieces.
3. Rooftop Penthouse — the full detail, five pieces, then the getaway.

Every room has more than one route: slip behind a guard, cut through a
side corridor, or spend a gadget to buy a quiet window. Sounds are
synthesized in the browser with Web Audio, and the whole game is static
files with no network requests.
